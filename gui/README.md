# Dotfiles GUI

Лёгкое приложение на Python / Tkinter: тёмная тема, мягкие фиолетовые акценты,
без pip-зависимостей, браузера и фоновой службы. Подключение использует GNU Stow
и существующую логику `dotctl.py` из родительского каталога.

Округлые кнопки и карточки, мягкое выделение строк, плавная подсветка при
наведении и фокусе, переходы заголовков и индикатор работы нарисованы средствами
Tkinter. Анимации короткие и прекращаются после перехода; пульсация работает
только во время выполнения операции. Отключить эффекты можно флагом:

```sh
python3 gui/app.py --no-animations
```

## Запуск

Ubuntu / Debian:

```sh
sudo apt install python3 python3-tk stow
python3 ~/.dotfiles/gui/app.py
```

Arch:

```sh
sudo pacman -S python tk stow
python3 ~/.dotfiles/gui/app.py
```

В WSL2 окно отображается через WSLg при его наличии. Запускайте Python **внутри
Linux**, чтобы ссылки и Stow работали в той же системе, что и ваши конфиги.
Windows Python подходит для проверки интерфейса, но для подключения конфигов
Linux нужен запуск в WSL.

Для проверки без изменения домашних конфигов:

```sh
mkdir -p /tmp/dotfiles-gui-home
python3 gui/app.py --repo "$PWD" --target /tmp/dotfiles-gui-home
```

Пути также можно изменить кнопками в окне. Настройки действуют на текущий
сеанс; приложение не создаёт собственного конфигурационного файла.

## Работа

- **Пакеты:** поиск, состояние, подключение выбранных или всех пакетов,
  отключение выбранных. Ctrl / Shift позволяют выбрать несколько строк.
- **Бэкапы:** удаление отдельных копий или всех копий существующих пакетов.
- **Старые ссылки:** очистка по пакетам или всех ссылок на удалённые файлы.
- **Добавить пакет:** системный выбор файла или папки, имя пакета,
  предварительный просмотр вложенной структуры. Исходники остаются на месте.

Перед изменениями приложение показывает подробный список и просит нажать
«Выполнить», «Создать» или «Удалить». До подтверждения файлы не меняются.
Обработка выполняется в рабочем потоке; на время операции кнопки блокируются.
Окно не закрывается, пока операция не завершена.

Ограничения и правила бэкапов общие с CLI: см. [основную инструкцию](../README.md).
Если пакет уже существует, подключайте его в списке пакетов; мастер создания
не перезаписывает существующие пакеты.

## Проверка

```sh
python3 -m unittest discover -s tests -v
python3 gui/smoke_test.py
```

Вторая команда требует доступного графического окружения. Она проверяет
построение окна, переключение разделов, фильтрацию и модальные окна на
временном репозитории, затем закрывает приложение.
